Atlas of Nations is an original national statistics explorer: real World Bank figures (2014–2023) for ten countries — population, GDP per capita, life expectancy, unemployment, infant mortality and GDP growth — with ranked bar charts, ten-year line charts, country profiles and a side-by-side comparison view, in a static site that works on desktop and phone with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
